# QMemory v0.9 Memory Map

## Decision

The memory map is the default workbench view. The task list remains one click away and is the
preferred surface for search and dense scanning. The map exists to explain provenance and
transformation, not to decorate the archive.

## Graph grammar

```text
Project
  └─ Task (up to four contextual siblings)
      ├─ Codex / Claude Code source groups
      │   └─ subagent execution branches
      └─ L0 raw conversation → L1 atomic memory → L2 project scenario → L3 stable kernel
```

- One user task has one highlighted task node even when several Agents contributed copies.
- Every source and subagent node opens the actual archived conversation in the evidence panel.
- Every layer node changes the same inspector used by the list view; map and list never create
  separate selection state.
- L0 is selected first. L1 shows only memories with explicit source references. L2 and L3 retain
  honest empty states until the isolated processor produces traceable output.
- The canvas shows at most four task siblings and four branches at once. Dense exploration stays
  in the list; later releases may add pan/zoom only when real projects prove it necessary.

## Interaction and accessibility

- `图谱 / 列表` is a persistent two-state switch and the last choice is restored.
- All nodes are real focusable buttons, not painted hit targets. Enter/Space activates a node.
- Color is redundant with node labels and selection borders.
- Selecting a task, source, branch, or layer updates the right inspector without opening a modal.
- The 1440×900 layout shows the complete graph without scrolling; the 980×650 layout preserves
  the list fallback and never introduces horizontal scrolling in evidence text.

## Visual tokens

- Existing v0.8 light canvas and purple interaction accent remain canonical.
- Codex uses cyan only as source metadata; Claude Code uses violet only as source metadata.
- Gray edges mean structural relation; purple edges identify the selected provenance path.
- No decorative shadows or animated force layout. Stability and traceability are more important
  than visual spectacle.
